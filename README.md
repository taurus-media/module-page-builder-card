# Page Builder Card module #

### Main Features: ###

* Introduced a new content type 'Card' in Magento Page Builder
* Possibility to have short cards (with image and title only) and long cards (with image, title, description and read more link)
* Default styling for Luma theme
* Default styling for Hyva theme
* On mobiles, cards displayed as a slider
* Possibility to select columns layout fot mobiles and tablets

### Usage
1. Add a 'Columns' element in Page Builder
2. Add class name 'pagebuilder-card-list' to the Columns element
3. Configure the necessary number of columns
4. Add a 'Card' element into every column
